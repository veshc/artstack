# Worked example: live payment status

One feature from the example Orion train (see `context/examples/`) walked end to end through ArtStack: feature brief, /pi-prep decomposition, /test-plan, a generated test, and /demo-prep. Outputs are abridged for readability; real runs are longer.

Order:

1. `00-feature.md` the feature as written in Azure DevOps
2. `01-pi-prep.md` /pi-prep output: stories, risks, load
3. `02-test-plan.md` /test-plan output: risk-ranked coverage
4. `03-automate.spec.ts` one Playwright spec produced by /automate
5. `04-demo-prep.md` /demo-prep output: the system-demo segment
